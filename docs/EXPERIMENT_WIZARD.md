# 三步创建实验

当前创建流程固定为三步：

1. **标的选择**：选择已导入标的、K 线级别，再确定行情快照；显示数量和时间范围。
2. **选择特征**：复用因子集或手动勾选 1–30 个因子；可搜索名称与分类。切换因子集后再切回手动选择，会恢复原勾选。
3. **选择模型**：实验名称、模型、预测目标和该模型的训练参数放在一起。没有单独的训练、评估或交易配置步骤。

支持「上一步」「下一步」及步骤导航。前进和最终提交都会校验先前步骤；回退保留表单内容。复制实验恢复数据、特征、模型和已保存的自定义参数。

## 标的与级别

Binance 新导入数据保存 `symbol`、`interval` 元数据；CSV 导入界面也要求填写这两个字段。实验最终绑定 `dataset_id`，因此筛选只展示实际存在的快照，不会静默重采样或把另一周期数据用于训练。

历史 Binance 数据可从平台原先生成的标准名称读取元信息。未标注的旧 CSV 以各自的原始快照展示，级别显示「原始级别（未标注）」，不会通过文件名猜测标的或周期。需要规范标注时可重新导入。CSV 周期是用户声明的元信息，不会据此重采样文件内容。

## 模型与训练参数

模型库和模型选择按「树模型、时序模型」分组。新实验优先选择可用的 LightGBM；不可用时依次选择 XGBoost、LSTM、GRU（同时检查任务支持）。复制实验保留仍受支持的原模型，即使依赖不可用也不会静默替换，提交时提示不可用。CNN-LSTM 和 Ridge / Logistic 已移除，复制这些历史实验会显示「原模型已移除，请重新选择」。历史结果和导出继续可用。

| 模型 | 可配置 |
|---|---|
| LightGBM | 最大迭代轮数、最大树深、最大叶子数、学习率 |
| XGBoost | 迭代轮数、最大树深、学习率、样本采样比例、特征采样比例 |
| LSTM | 学习率、批大小、隐藏维度、历史窗口、训练轮数 |
| GRU | 学习率、批大小、隐藏维度、历史窗口、训练轮数 |

参数 schema 由后端模型目录提供，前端按任务动态生成表单。所有参数在后端再次验证；拒绝未知参数、非法类型、越界值以及不合理的树深/叶子数组合。缺省参数补齐后保存到实验快照的 `config.model_params`，训练与重复诊断使用同一份参数；结果中记录实际生效值。旧实验未记录该字段时使用原默认参数。

评估仍在训练后自动运行，创建界面不再显示评估设置。新实验使用固定时间切分与单次训练；此前保存的诊断报告不删除。交易门槛和成本不出现在三步表单，新实验采用后端默认值，复制旧实验时保留其原有执行参数；需要调整时进入独立回测。

## 实现与验证

- `quant/model_config.py`：模型参数声明、默认值与校验。
- `quant/models.py`：参数传入真实估计器/网络，保存架构及训练诊断。
- `quant/app.py`、`quant/data.py`：模型配置快照、标的与级别元数据。
- `web/experiment-wizard.mjs`：步骤、联动选择、参数表单与提交校验。

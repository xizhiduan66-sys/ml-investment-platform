# 一、二类买卖点结构分类

在「新建实验」第一步选择标的、周期和时间范围，将采样方式切到「事件采样」。勾选一买、一卖、二买或二卖。进入下一步时，系统为选定区间生成或复用行情快照。第二步可混合选择缠论和普通量价因子。第三步选择结构确认或已有收益目标，并配置 LightGBM 或 XGBoost。

## 公开源码与固定计算口径

使用 MIT 许可的 Vespa314/chan.py 公开计算模块，锁定提交 f8ca3b5e44d7166e2abd756a8e7fa816c79faebe。命名空间和 Python 3.9 类型注解适配见 quant/vendor/chanpy/UPSTREAM.md，算法未修改。

单周期逐根输入，严格笔，标准 T1、T2 买/卖点。暂不包含 T1P、T2S 和三类点。候选采用峰值背驰门槛 1.0，至少一个中枢，二类点要求关联一类点；完整配置记录在实验 snapshot.chan。模型是在此候选集合上学习结构保留概率。

## 事件与标签

身份为「类别 + 买卖方向 + 原始拐点 K 线索引」，逐根计算完成后对账，避免把删除后重建误认为失效。拐点迁移到另一根 K 线产生新的事件；同一身份消失后重现不重复建样本。

特征与首次可见时间在事件创建时冻结。标签等到 anchor <= bs_point_lst.last_sure_pos 后才成熟：当前集合保留为 1，撤销为 0。这是所锁定版本不再清理重算的买卖点前缀边界，不是交易止损或盈利标签。边界回退报错，不能静默重新标注。

未到冻结边界的事件保持 pending，不当作正例。首次出现就已在冻结区间的事件可供观察，但不训练。负样本不会因为最终图上已消失而被丢弃。选收益目标时，每个事件使用首次可见后的下一根开盘到第 h + 1 根开盘的收益。标签可知时间为区间结束时刻，独立于结构状态。

## 特征

- 背驰峰值比：一类点离开中枢笔 / 进入中枢笔的 MACD 峰值；二类点取当前关联一类点对应的笔对。
- 背驰面积比：同一笔对的 FULL_AREA，即笔区间内与方向一致的柱面积比。
- 二类点回撤比例：回撤笔 / 前一突破笔振幅；一类点为 0。
- 买卖方向：买 1、卖 -1。
- 类型：一类 1、二类 2。

默认选择前两个，可自行增选其他三个。参考笔缺失、分母接近零时记缺失，不能填零假装没有背驰。只有所选特征全部有效的事件参与训练。

## 训练与观察

按原始行情时间轴 60/20/20 切分，事件归属由首次可见时刻决定；标签确认时间到达下一分区的事件剔除。测试区间末尾 pending 不参与评估。训练至少80，验证、测试各30个有效事件；训练标签需包含两类。数据不足时提示增加历史数据，不降低标准或制造样本。

复用二分类 AUC、PR、Log Loss、Brier、校准和混淆矩阵诊断。事件详情显示样本外保留概率，完整事件生命周期、快照和结果可从实验 JSON 导出。预览接口 GET /api/chan-events/{dataset_id} 提供完整事件记录。

事件不自动转仓位，不显示虚构净值，也不能经回测 API 当作上涨概率执行。买卖点撤销样本通常很多，需结合 PR、正类比例与校准判断；多个候选点可能共享一个结构，时间分段指标不是独立样本置信区间。

## 验证

测试覆盖实际公开引擎四类点生成、回放前缀特征不变性、冻结标签稳定性、删除重建、首现即冻结排除、真实标签结束时间隔离、完整 API → 训练 → 导出流程，以及交易回测语义隔离。使用临时合成行情，不写入实际工作数据。

# 代码审查与修正记录

审查范围：行情读取、因子契约、训练与标签边界、交易执行、结果持久化、前端结果说明。修正以研究结果的一致性和可追溯性为主，保留现有界面和插件扩展方式。

## 已修正

| 优先级 | 原问题 | 修正 |
|---|---|---|
| P1 | 实验按收益比例扣费，独立回测按订单与现金记账，同样信号可能产生不同结果 | `engine.simulate` 改为统一 `backtest.run` 的报告适配器；成交、成本与期末平仓统一为 `order-v2` |
| P1 | 独立回测结束于最后一个预测所在 K 线，漏掉其下一根开盘成交；单个信号也被拒绝 | 回测区间延长至最后一个信号后一根；支持单个有效预测 |
| P1 | 因子 IC / 相关性默认读取全量样本，筛选因子可能泄漏测试集信息 | 默认训练区间，计算前截断行情，标签终点不得越界；API 返回评价范围，前端明确显示 |
| P1 | 快照记录了 SHA256，但读取时未检查实际文件 | 每次数据读取校验内容哈希，篡改后拒绝继续训练或回测 |

| P2 | 跳空已越过止盈线，但后续 low 触及止损时被错误判为止损 | 先判开盘跳空，再判盘中触线；盘中路径不明时保留止损优先 |
| P2 | 短区间大涨使年化溢出，导致整份 JSON 无法保存 | 无法表示的年化指标返回 null；移除重复首个零收益样本，按实际跨度推算年化频次 |
| P2 | 期末平仓后仓位为零，短期持仓的暴露比例被低估 | 记录当根是否发生持仓，排除初始信号行 |
| P2 | 因子索引错位可能静默对齐，声明的缺失策略和必需列未落实 | 严格检查索引、输出类型、scope、缺失策略及输入列；neutral 填零；拒绝非有限参数 |
| P2 | 样本上下文内部持有完整未来数据，历史访问返回可变引用 | 内部仅持有历史前缀，公开历史/当前 K 线接口返回副本 |
| P2 | SQLite 上下文只结束事务，不关闭连接；更新会改变列表排序 | 显式关闭连接，使用 UPSERT 保持创建顺序 |
| P2 | 两个回测入口成本默认值不同，界面比较容易误解 | 实验来源的 API 默认继承成本，前端切换实验时同步手续费并清零滑点；回测报告显示引擎版本 |
| P2 | Binance 解析与回测内部未完整拒绝非有限价格 | 加入有限值检查，避免无穷值污染结果 |

因子评价同一请求的 IC 与相关性复用一份特征矩阵，避免重复运行插件。样本上下文内部使用历史前缀浅拷贝，避免每根 K 线都深复制全部历史；公开访问接口仍返回副本。

## 使用影响与剩余边界

- 重启本地服务后，新实验和回测使用 `order-v2`。历史 JSON 不修改，新旧曲线可能不同，这是成交和费用口径修正的结果。
- `cost_bps` 现在作为真实单侧手续费；独立回测可额外设置滑点。新增结果保存执行口径及引擎版本。
- 当前生产插件目录只有模板，没有实际均线或缠论因子；已有 SMA 回测信号不等同于训练用因子插件。
- 任意向量化插件仍需因果性测试；上下文不是 Python 代码安全沙箱。
- 保留单进程、进程内串行训练部署。持久队列、任务取消、多服务并发、结构层、损失注册和模型加载接口不在本轮实现范围。
- 固定时间切分仍不能替代滚动样本外验证。快照记录代码哈希与版本信息，但不会自动恢复历史源代码。

架构与扩展位置见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 后续变更：移除单标的 IC

因子评价曾按多标的惯例输出与未来收益的 Spearman「IC」。该指标需要横截面，单标的下退化为时序秩相关，且重叠标签使精度被高估（h=20 时有效样本约 29 个）。现已删除 `ic_*`、`horizons` 参数，以及覆盖率/分布统计，只保留特征间 Spearman 相关矩阵；切分口径从特征模块移到 `quant/splits.py`，特征模块只接收切好的矩阵。预测力改由实验与回测判断。

# 前端界面与交互优化

## 正式界面

- 默认打开「实验中心」，顶部可以新建实验，下方显示最近实验。历史记录支持搜索、筛选和对比。
- 「回测中心」提供运行入口和最近一份回测。可从 SMA 规则或实验预测直接进入对应配置。
- 「研究资产」包含特征、特征集、训练任务和模型。特征按分类浏览，训练任务按回归、二分类分组，可带入新建实验。
- 「行情数据」以 K 线为主，旁边显示当前标的和周期的入库范围、同步操作及报告。可将库内区间保存为行情快照，供 SMA 回测和研究资产预览使用。

## 量化研究原型

[打开交互 Demo](mockups/research-workbench.html)。实验中心集中展示新建实验入口、研究资源和已有结果。回测中心把运行入口、信号说明和近期示例报告放在同一页。新建和运行都直达本地正式系统的表单。

- 研究资产来自 `GET /api/catalog` 的实现。特征按注册分类显示，训练任务按回归和二分类分组，模型参数来自对应任务的参数声明。
- 因子取值使用 `GET /api/preview/{dataset_id}` 的实现。普通特征随 K 线对齐，事件特征显示观察时间、事件类型和取值。当前仓库只有缠论事件特征。
- 实验和 SMA 回测使用同一份合成行情，在临时数据目录调用真实训练和订单引擎。事件实验的预测目前需要独立的交易执行规则。

用 `.venv/bin/python -m scripts.export_workbench_demo` 更新目录和示例。导出使用独立的临时目录，行情为固定种子生成的合成数据。浏览器可以直接打开生成的文件。

## 交互修正

1. 轮询更新实验中心的最近实验、历史列表或实验详情。页面隐藏或打开弹窗时暂停轮询。
2. 页面渲染和预览请求有版本检查，较早请求不能覆盖较新的选择；特征相关性与比较面板也校验当前请求身份。
3. 弹窗查询优先作用于弹窗内部，避免与背景回测表单的同名字段发生冲突。
4. 表单防重复提交，展示处理中状态，处理错误后恢复按钮；提交中的弹窗禁止关闭。
5. 回测隐藏的信号来源字段同时禁用，避免无关 required 字段阻止提交。
6. 因子/模型不同是实验对比的研究变量，不再被视作比较条件不一致；实际检查数据、标签语义、测试时间点、成本、开仓门槛和执行版本。
7. 曲线按各自样本进度归一到同一横轴终点；不同日期范围仍明确提示不能直接视为严格对照。

## 文件职责

- `web/app.js`：页面、表单、事件、API 调用及请求生命周期。
- `web/ui-state.mjs`：可独立测试的搜索、比较、分页、请求版本和轮询目标规则。
- `web/style.css`：基础样式与本轮研究流程、弹窗、响应式样式。

# 前端界面与交互优化

本轮沿用现有浅色研究台和无构建依赖的原生 JavaScript，调整研究流程、表单和异步状态，不修改后端 API 或计算规则。

## 可见变化

- 总览新增「准备行情 → 组织特征 → 训练与验证 → 检验交易」入口，显示各阶段已有资产数量。
- 实验中心支持按名称、数据、模型、目标搜索，以及按状态筛选；最多同时对比 4 个实验，勾选时保留列表和搜索状态。
- 新建实验分为数据范围、输入特征、训练设置、交易规则四组，侧栏实时显示输入数量、窗口、输出含义及固定时间切分。
- 选择因子集时展示实际成员；切回手动选择恢复之前的勾选。时序模型专用参数和当前任务不使用的开仓门槛隐藏且不提交。
- 缺少数据、因子或目标时，引导补齐前置资源；创建因子后自动选中新实例，CSV 导入后自动选中新数据。
- 已完成实验可直接跳转到回测，自动选择预测来源并继承成本；无数据或未完成实验时，禁用相应回测提交。
- 回测报告展示基准曲线、执行配置及实际订单明细；长记录列表只显示相邻分页，去掉未经数据确认的固定 USDT 标注。
- 改善文字对比度、焦点样式、窄屏布局、按钮状态、加载反馈及表单内错误展示；移除指标卡无实际含义的上升箭头。

## 交互修正

1. 轮询只更新任务状态、实验列表或实验详情，不重绘因子、数据和回测配置页；请求不重叠，页面隐藏或弹窗打开时暂停轮询。
2. 页面渲染和预览请求有版本检查，较早请求不能覆盖较新的选择；特征相关性与比较面板也校验当前请求身份。
3. 弹窗查询优先作用于弹窗内部，避免与背景回测表单的同名字段发生冲突。
4. 表单防重复提交，展示处理中状态，处理错误后恢复按钮；提交中的弹窗禁止关闭。
5. 回测隐藏的信号来源字段同时禁用，避免无关 required 字段阻止提交。
6. 因子/模型不同是实验对比的研究变量，不再被视作比较条件不一致；实际检查数据、标签语义、测试时间点、成本、开仓门槛和执行版本。
7. 曲线按各自样本进度归一到同一横轴终点；不同日期范围仍明确提示不能直接视为严格对照。

## 文件职责

- `web/app.js`：页面、表单、事件、API 调用及请求生命周期。
- `web/ui-state.mjs`：可独立测试的搜索、比较、分页、请求版本和轮询目标规则。
- `web/style.css`：基础样式与本轮研究流程、弹窗、响应式样式。
- `tests/test_ui.mjs`：Node 原生测试，无新增依赖。

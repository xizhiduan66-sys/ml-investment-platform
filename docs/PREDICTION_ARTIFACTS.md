# 预测产物与策略边界

新实验在模型推理完成后发布 `<experiment_id>.predictions.json`，实验报告只保存
产物引用和 SHA-256，同时保留原有逐行报告字段以兼容页面。
产物包含数据内容哈希、任务、采样方式、预测语义、样本 ID、观察时间及分区。
文件先写临时路径，再原子替换；此处尚未实现文件与数据库的统一恢复协议。

独立回测优先读取预测产物，只选择 test 分区，并校验文件内容和数据绑定。
旧实验没有产物引用时，继续从原有报告 rows 读取。存在引用但校验失败时拒绝回测，
不会静默退回旧数据。删除实验也会清理预测文件。

ThresholdPolicy 是当前第一种策略：预测严格大于阈值时做多，否则空仓；
缺失预测为空仓。决策后的下一根开盘成交仍由 backtest 引擎实现。
实验默认回测和独立回测共用此策略，手续费、滑点及风控由执行配置单独控制。

事件预测同样保存产物，但尚未提供事件交易策略，因此不能使用 K 线阈值策略回测。
当前预测文件使用 JSON 且整文件加载；分页、Parquet、大规模读取和策略插件注册
尚未实现。实验仍自动执行默认回测，独立回测已能复用预测而无需训练。

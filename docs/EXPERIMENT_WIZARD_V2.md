# 任务优先实验向导

五步：研究任务 → 数据与样本 → 特征 → 模型 → 确认运行。
第一步先选择 K 线收盘触发或事件触发，再选预测目标。事件规则在「研究资产」保存和预览，实验冻结规则版本及参数。RSI 在首次跌破阈值时触发，缠论按候选点首次可见的 K 线取样。
回归、二分类与多分类共用目标参数接口。未来收益分档由持有周期和收益上下界定义，类别依次为下跌、横盘、上涨。事件专属目标和特征限定到对应的事件来源。

确认页显示固定 60/20/20 时间划分、Worker 在线状态和后端兼容性检查。
预检查覆盖目标、特征清单、模型及参数；不宣称已验证有效样本数量，
该数量仍在实际计算特征和标签后验证。最终创建接口继续执行完整提交校验。

草稿目前保存到当前浏览器 localStorage（单槽位），不会自动提交，也不跨设备同步。
恢复后需重新核对行情区间。提交请求携带 submission_key，数据库事务去重。
原配置重跑仍通过独立 Run 接口，不进入此向导。

可取消自动回测，此时保存预测产物与诊断，结果类型为 prediction_only。
K 线回归与二分类可稍后从运行详情进入独立回测。事件任务和多分类任务提供样本外预测及诊断。多分类目前由 LightGBM 执行。

目前使用固定的时间切分比例。实验可引用特征集或手动选择特征。

## 通用事件规则

在「研究资产 → 事件规则」选择内置规则，调整参数后另存，再在新建实验的第一步选用。实验保留规则的版本与参数快照。

| 规则 | 可配置内容 | 触发口径 |
|---|---|---|
| EMA 均线交叉 | 快慢周期、方向 | 快线从慢线一侧穿到另一侧 |
| 唐奇安通道突破 | 历史窗口、方向 | 收盘首次越过前 N 根边界，轨道排除当前根 |
| 布林带进入与回归 | 窗口、标准差倍数、状态变化 | 进入轨外、回到带内或穿越中轨 |
| RSI 阈值穿越 | RSI 周期、阈值、方向 | 可配置跌破 30、上穿 70 或穿越 50 |
| 动量符号翻转 | 自然日窗口、方向 | 历史收盘收益率穿过零 |
| UTC 定时观察 | 每天或每周、星期、时分 | 使用指定 UTC 时刻刚收盘的 K 线 |
| 指定价位穿越 | 价位、方向 | 收盘穿越固定价格 |

交叉的前后两个观测均有效时才判断。一般上穿采用「前值不高于边界、本值严格高于边界」，下穿对称。布林回到带内包括恰好回到边界的情况。历史预览展示方向、观测值及对应参考边界，连续处于轨外的区间只在进入时产生事件。

定时观察需要等间隔、无缺口的行情，并检查时刻与 K 线收盘边界是否对齐。比如每周一 UTC 00:00 的 1h 样本使用周日 23:00 开始、周一 00:00 刚收盘的那根 K 线。预览同时展示该 K 线时间和实际可用时间。
